## 1. Hard constraints carried over from AGENTS.md (apply to every phase)

- **Database Identity Separation (AGENTS.md §12):**
  - `core_users`: system account / authentication identity (`user_id`). Used for `assigned_by_user_id` and `changed_by_user_id`.
  - `core_members`: official club member identity (`member_id`).
  - `adm_panel_memberships`: active term assignment (`panel_membership_id`). Connects member + panel term + position + team.
  - Assignees in `adm_task_assignees` connect to `panel_membership_id` (NOT raw `member_id`, NOT comma-separated strings).
- **No comma-separated assignee IDs anywhere** — assignees are always individual rows in `adm_task_assignees` unique on `(task_id, panel_membership_id)`.
- **Task statuses are strictly:** `TODO`, `IN_PROGRESS`, `BLOCKED`, `DONE`. No other spelling/casing/variant (`TODO`, `IN_PROGRESS`, `BLOCKED`, `DONE` only).
- **Status history is append-only:** Every status transition must be **inserted** into `adm_task_status_history`, never overwritten or deleted.
- **No new database table or column** without following the formal **Schema Change Proposal** process (AGENTS.md §14).
- **PostgreSQL syntax only, parameterized queries only** (`$1, $2, ...`) for all database operations.
- **Frontend route guards are UX only** — backend must enforce auth/RBAC/ownership regardless of what the frontend sends.
- **Cross-module boundaries (AGENTS.md §9, §11):** `administration/` must never import `event-management/`. Shared Features may be consumed, but Shared Features must never depend on Administration.
- **Design system compliance:** Work must follow `docs/design/DESIGN_SYSTEM.md`, `MOTION_SYSTEM.md`, `COMPONENT_STANDARDS.md`, and `src/styles/design-tokens.css`. Brand colors: Deep AUSTRC Green `#006838`, Bright AUSTRC Green `#39B54A`. No module-specific themes. Reuse existing primitives from `shared-features/frontend/components/`.

### Phase 0 Output: Canonical Schema Contract

#### 1. `adm_tasks` (Owner: Administration Team)
- `task_id`: `BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY`
- `panel_term_id`: `BIGINT NOT NULL` (FK → `adm_panel_terms.panel_term_id` `ON DELETE RESTRICT`)
- `team_id`: `BIGINT NOT NULL` (FK → `adm_teams.team_id` `ON DELETE RESTRICT`)
- `assigner_membership_id`: `BIGINT NOT NULL` (FK → `adm_panel_memberships.panel_membership_id` `ON DELETE RESTRICT`)
- `task_title`: `VARCHAR(255) NOT NULL`
- `task_description`: `TEXT NULL`
- `priority`: `VARCHAR(30) NOT NULL DEFAULT 'MEDIUM'` (allowed: `'LOW'`, `'MEDIUM'`, `'HIGH'`, `'CRITICAL'`)
- `status`: `VARCHAR(30) NOT NULL DEFAULT 'TODO'` (allowed: `'TODO'`, `'IN_PROGRESS'`, `'BLOCKED'`, `'DONE'`)
- `due_at`: `TIMESTAMPTZ NULL`
- `blocked_reason`: `VARCHAR(500) NULL`
- `completed_at`: `TIMESTAMPTZ NULL`
- `created_at`: `TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP`
- `updated_at`: `TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP`
- Indexes: `idx_adm_tasks_team_status (team_id, status)`, `idx_adm_tasks_due_at (due_at)`, `idx_adm_tasks_assigner (assigner_membership_id)`

#### 2. `adm_task_assignees` (Owner: Administration Team)
- `task_assignee_id`: `BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY`
- `task_id`: `BIGINT NOT NULL` (FK → `adm_tasks.task_id` `ON DELETE RESTRICT`)
- `panel_membership_id`: `BIGINT NOT NULL` (FK → `adm_panel_memberships.panel_membership_id` `ON DELETE RESTRICT`)
- `assigned_by_user_id`: `BIGINT NULL` (FK → `core_users.user_id` `ON DELETE SET NULL`)
- `assigned_at`: `TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP`
- `status`: `VARCHAR(30) NOT NULL DEFAULT 'ASSIGNED'` (e.g. `'ASSIGNED'`, `'IN_PROGRESS'`, `'COMPLETED'`)
- `completed_at`: `TIMESTAMPTZ NULL`
- `created_at`: `TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP`
- `updated_at`: `TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP`
- Constraint: `uk_adm_task_assignees UNIQUE (task_id, panel_membership_id)`
- Index: `idx_adm_task_assignees_membership (panel_membership_id)`

#### 3. `adm_task_status_history` (Owner: Administration Team)
- `task_status_history_id`: `BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY`
- `task_id`: `BIGINT NOT NULL` (FK → `adm_tasks.task_id` `ON DELETE RESTRICT`)
- `from_status`: `VARCHAR(30) NULL`
- `to_status`: `VARCHAR(30) NOT NULL`
- `changed_by_user_id`: `BIGINT NULL` (FK → `core_users.user_id` `ON DELETE SET NULL`)
- `reason`: `VARCHAR(500) NULL`
- `created_at`: `TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP`
- Index: `idx_adm_task_status_history_task (task_id)`
